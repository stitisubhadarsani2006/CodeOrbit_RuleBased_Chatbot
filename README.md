# Rule-Based Chatbot

A simple rule-based chatbot project developed as part of the CodeOrbit
Tech Artificial Intelligence Internship.

## Project Overview

This project demonstrates how a chatbot can respond to user messages
using predefined rules, keywords, and pattern matching. Instead of using
a machine-learning or large language model, the chatbot checks the
user's input against predefined rules and provides an appropriate
response.

The project includes a simple web-based interface for interacting with
the chatbot.

## Features

-   Rule-based chatbot responses
-   Handles common greetings and questions
-   Uses predefined keywords and patterns
-   Provides a fallback response for unknown inputs
-   Simple and user-friendly web interface
-   Displays chatbot responses dynamically
-   Beginner-friendly implementation

## Technologies Used

-   HTML

## How It Works

1.  The user enters a message in the chatbot interface.
2.  The input is processed and checked against predefined rules or
    keywords.
3.  If a matching rule is found, the chatbot provides the corresponding
    response.
4.  If no matching rule is found, the chatbot gives a fallback response.
5.  The conversation is displayed in the chatbot interface.

## How to Run

1.  Download or clone this repository.
2.  Open the project folder in Visual Studio Code.
3.  Make sure all the project files are in the same folder.
4.  Open `index.html` in a web browser.
5.  Enter a message in the chatbot and interact with it.

If you use the Python component directly, make sure Python is installed
and run the Python file according to its implementation.
